# Foto produk hockey

Semua foto yang dipakai website berada di folder ini. Untuk mengganti foto, timpa file terkait dengan gambar baru dan pertahankan nama filenya. Format JPG, PNG, JPEG, atau WebP dapat digunakan; bila ekstensi berubah, sesuaikan path pada `photos.js`.

| File | Isi |
|---|---|
| `hoki-indoor.jpg` | Foto pria bertanding indoor, dipakai pada bagian Indoor Hockey |
| `hoki-outdoor.jpg` | Foto pemain wanita menggiring bola dengan lawan berbaju merah di belakang |
| `hoki-hero-putih.jpg` | Foto pemain wanita berseragam putih dan sepatu putih di bagian Ready for the Shift |
| `produk-01.jpg` sampai `produk-20.*` | Foto produk sesuai nomor ID katalog; produk 01 adalah foto stik hoki Grays |

Foto produk 16, 17, dan 20 sudah diperbarui dengan bantalan kiper CCM, blocker TRUE, dan roll tape hoki Renfrew.

Kredit dan tautan sumber foto tercatat di `photo-sources.md`.
